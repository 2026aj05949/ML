# The objective is to classify mobile phones into different price categories using machine learning classification algorithms and compare their performance.

Six machine learning classifiers, namely Logistic Regression, Decision Tree, KNN, Naive Bayes, SVM, and Random Forest, were implemented and evaluated on the Mobile Price Classification dataset. Performance was measured using Accuracy, Precision, Recall, F1-Score, MCC, and AUC (where available). Among all models, Random Forest achieved the highest Accuracy (98.00%) and MCC (0.9733), demonstrating superior classification capability. Decision Tree also showed excellent performance with 97.25% accuracy. Therefore, Random Forest is selected as the optimal model for this dataset due to its robustness, accuracy, and generalization ability.
